# Call when

Call for formal-vs-challenger overlap, known-item tests, source overlap, or
query-gap review.

# Do not call when

Do not use QA output to inflate formal database counts or to hide a query gap.

# Required outputs

Write the overlap matrix, delta sets, gap classifications, and metrics such as
known-item recall, formal/challenger overlap, and dedup review rate.
