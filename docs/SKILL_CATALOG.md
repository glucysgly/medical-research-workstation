# Research Skill Catalog

The authoritative capability inventory is the dated global tooling index. This
project keeps only a research-oriented derived view in
`registry/SKILL_CATALOG.csv`; it intentionally omits unrelated skills and does
not duplicate the global database. Review the global index before adding a row.

Each row records domain, trigger, primary skill, inputs, outputs, and minimum
validation. Current rows cover literature, data validation, nature-style data,
qPCR/omics evidence, Zotero, and NGS routing.
