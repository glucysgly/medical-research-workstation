# Public-omics template

Use this workspace for public transcriptomic, epigenomic, proteomic, or other
omics data. Dataset access must be verified and versioned; public status never
permits copying identifiers or controlled data. Raw downloads are immutable.
Predefine the biological unit, sample metadata, primary contrast/estimand, QC,
normalization, batch strategy, multiple-testing rule, and validation path.
Separate direct dataset facts, literature evidence, and exploratory hypotheses.
