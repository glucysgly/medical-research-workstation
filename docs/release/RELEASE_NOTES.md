# Release notes / 发布说明

## v1.0.0-rc1 — 2026-08-09

### English

This release candidate packages the v5.1 research control-plane ideas as a
portable public framework. It includes deterministic project metadata,
routing contracts, privacy/statistical safeguards, provenance/reproduce
interfaces, Codex and Claude adapters, synthetic examples and local release
auditing.

It deliberately excludes the internal workstation baseline, real Production
Pilot, patient/restricted data, private notes, Zotero attachments, credentials,
large raw sequencing data and unverified third-party bundles.

### 中文

本候选版本将 v5.1 的科研控制层整理为可复用的公开框架，包含项目元数据、任务
路由契约、隐私与统计单位保护、provenance/reproduce 接口、Codex/Claude 适配器、
synthetic 示例和本地发布审计。

公开版明确排除内部工作站基线、真实 Production Pilot、患者/受限数据、私人笔记、
Zotero 附件、凭据、大型原始测序数据和未经审计的第三方能力包。

### Status

This is a release candidate for human review. It is not a clinical, diagnostic or
publication-readiness guarantee.
