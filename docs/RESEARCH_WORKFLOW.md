# v5 Research Workflow

1. Resolve the project and read `project.yaml` plus `status.yaml`.
2. Classify the task code and select the smallest domain pack and primary Skill.
3. Verify privacy, ethics/access, source metadata, raw hashes, and statistical unit.
4. Lock protocol fields: outcome/contrast, estimand, model, missingness, outliers,
   multiplicity, and validation path.
5. Run deterministic analysis with a run ID; write only derived data/results.
6. Record commands, versions, hashes, warnings, outputs, evidence, and limits.
7. QA the figures/tables/manuscript and update status and retrospective.

No verified source means no formal citation. Exploratory association is not causal
evidence. Raw data is never cleaned in place.
