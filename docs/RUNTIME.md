# Runtime contract

Before execution, check the selected tool, version, login/connection status,
working directory, and data location. Prefer Windows for workstation/files and
WSL for Linux-first bioinformatics when compatible; keep large projects on D:.
Record executable, version, command, environment, and exit code in provenance.

Do not install packages, download large data, or create proxy/daemon state as an
implicit step. A missing runtime is a blocked prerequisite, not a reason to fake
results.
