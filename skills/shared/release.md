# Shared release contract

Before public release:

- scan current files and the candidate history;
- remove private paths, credentials, PHI/PII, raw data and private notes;
- record third-party source and license decisions;
- run unit tests, synthetic smoke and package inspection;
- report PASS/WARN/FAIL/BLOCKED/UNVERIFIED/DEFERRED honestly;
- stop for human review when a license, identity, data or history decision is
  unresolved.
